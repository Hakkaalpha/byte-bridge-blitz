# Tech Embrace Portfolio

Create a modern, sleek, dark-themed personal portfolio website for a first-year B.Tech Electronics and Communication Engineering student. The website must be built using React and Tailwind CSS and be fully mobile-responsive. Include a sticky navigation bar with smooth scrolling. Please generate the following sections:

Home: A hero section with a brief, punchy introduction, a placeholder for my profile picture, and a 'Download Resume' button.

About Me: A short bio highlighting my passion for bridging hardware and software, embedded systems, and artificial intelligence.

Education: List my B.Tech in ECE at JECRC University (2026-present) and my RBSE Class 12 Science background.

Skills: Categorize into 'Languages' (C, C++, Python), 'Web Dev' (React, Next.js, Tailwind, Flask), 'Hardware' (ESP32, PCB design), and 'Tools' (Manim, Git, Linux, VS Code).

Projects: Create a grid layout featuring 'Global Nexus AI Discord Bot', 'CampusBuddy AI', 'Custom Drone Design', and 'The Terminal Science Educational YouTube Channel'.

Certifications/Achievements: Highlight 'Unified Cyber Olympiad - All India Rank 518'.

Contact: A clean form with fields for Name, Email, and Message.
